# GrooveAccess

*A Garibaldi Production*

Web-first groovebox for techno, DnB, dub and jungle. Runs in desktop Chrome/Edge and Silk on a Fire tablet; nothing to install.

**Live build:** https://eojg1225-cell.github.io/groovebox/

Spec: [`groovebox-brief.md`](groovebox-brief.md). Architecture: [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Launcher (home-screen icon)

The app is installable, so it opens full screen in landscape from its own icon and also works offline once it has loaded.

- **Fire tablet (Silk):** open the URL, tap the menu (⋮ / ☰), choose **Add to Home Screen**, confirm.
- **Desktop Chrome/Edge:** click the install icon at the right of the address bar (or menu → *Install GrooveAccess* / *Apps → Install this site as an app*).

In a normal touch-browser tab, "Tap to start" also switches to full screen.

## Develop

```sh
npm install
npm run dev        # dev server (also on your LAN, for testing on the tablet)
npm test           # offline engine tests in Node (Vitest)
npm run build      # typecheck (incl. DOM-free engine check) + static build into dist/
npm run preview    # serve dist/ locally
npm run build:artifact  # also pack a single-page copy into dist-artifact/ for publishing as a claude.ai Artifact
```

Note: AudioWorklet needs a secure context, so on another device use the HTTPS Pages URL (plain `http://<lan-ip>` will not start audio).

## Current state

A title screen fades into the panel; the first touch switches sound on (browsers require a gesture). The instrument is always landscape (full screen + orientation lock on touch devices where allowed; rotated layout on portrait screens). Every start is a blank slate: a new project with a sound on every track and empty patterns, nothing routed to the FX; saved projects wait in their slots (LOAD).

**Layout (like a hardware front panel):** screen top left; top right MODE (RECORD / PLAY / DESIGN / SONG), channels 1-8 with M / S, the DESIGN pages (SOUND / MIX / PROJECT) with the small **FX 1 2 3 LFO** buttons beside them, and below those SAVE / SAVE PROJECT / RESET with the **PAT A B C D** buttons under the FX ones. Below: eight recessed track modules (two knobs each, track number between), the function row, step lights, the 16-button strip, and bottom right PLAY with the **TEMPO** and **MASTER** knobs.

**Knobs** are absolute 0-127 controls with fixed limits and a 270° sweep (TEMPO moves in 0.1 BPM steps). Drag vertically (400 px = full range, Shift = fine), double-tap resets. The control layer also accepts relative **encoder** turns (one detent = one step), as physical rotary encoders on the hardware will send; on screen the mouse wheel uses that path.

**Tracks:** 1 KICK, 2 SNARE, 3 HAT, 4 BASS, 5 PAD (chords), 6 LEAD.

**Eight tracks, 16 knobs:** 1 KICK, 2 SNARE, 3 HAT, 4 PERC (toms / percussion, pitched from the sequencer: step entry on the keyboard), 5 BASS, 6 PAD (held chords), 7 LEAD, 8 PLUCK (pluck synth with an ARP) (any track can be any type). Eight knob modules, one per track; four patterns A-D per track on the **PAT A B C D** buttons: plain = the selected track, **FUNC + A-D** = every track, **hold a channel button + A-D** = that track without selecting it (channel buttons select on release). **Each pattern has its own patch** (sound + SOUND page trims; the track type is the same for all four). RECORD / DESIGN: A-D choose the pattern you edit, with its patch. PLAY: A-D prime the switch for the loop end and the sound **glides** from the moment you press until it lands (coarse settings like OCTAVE, ROLL RATE, ARP, CHORD switch at the line; pressing the playing pattern again cancels and glides back; live knobs carry over). **SAVE**: RECORD = the track's pattern notes, DESIGN = its patch, PLAY = both; FUNC + SAVE = every track. Edits since the last SAVE are marked * (screen header and the A-D button); RESET returns to the saved versions. SAVE PROJECT saves every pattern and patch.

**ARP** (PLUCK): while a note is held, its chord (CHORD knob: MAJOR … MIN11, MAJ11, 5TH, 5TH+OCT) over ARP OCT octaves (1-3) is played in turn: UP, DOWN, UP/DN, CASC UP (overlapping skips: 1 5 3 7 5 9 …), CASC DN (from the top: 11 7 9 5 7 3 …), RANDOM, at 1/4 … 1/32 incl. triplets. Hold sequenced notes longer (tie, or RING) for longer runs; it plays live too.

**SONG mode** (4th mode button): a tracker-style grid. Each row lasts BARS bars and gives every track a pattern (A-D) or OFF (silent); at a row start every track restarts its row pattern, and the song loops from the top after the last row. Knobs: top = each track's pattern in the cursor row, bottom 1 = BARS, 2 = ROW. ◀ ▶ = column, ROW ▲ / ▼ = row, INSERT ROW (a copy of the cursor row, after it) / DELETE ROW, A-D (or hold a track + A-D) set a cell, FUNC + A-D the whole row; a row change glides each sound over the old row's last bar, the strip = rows (tap to move; while the song plays, it jumps there at the next bar). PLAY in SONG mode plays the song from the cursor row, sample-accurately in the engine, and keeps playing when you switch modes to tweak sounds; PLAY elsewhere plays the patterns as before.

**Three layers, each on top of the one below:** live knobs > SOUND page > TIMBRE / INTENSITY. TIMBRE picks the sound (coarse: waveform, FM ratio, layer balance, a designed value for every parameter); INTENSITY sets the amount of modulation / atmosphere — at 50 % the sound as designed, down to 0 its FM, filter envelope, sweep, noise, click, drive and width converge on a dull floor (PERC becomes soft thuds, SAW PLUCK no harsher than GLASS) keeping a 2 % trace of the TIMBRE; above 50 % FM follows a DX7-style taper (75 % = operator level 60, the top quarter runs on to 99 — the bite lives there) while width, drive and brightness only rise a little. Between TIMBRE's sounds FM ratios step through related ratios (1, 4/3, 3/2, 2 …) instead of smearing. SOUND page knobs adjust on top: a change to a parameter TIMBRE / INTENSITY also set is kept as an offset (a trim), so moving TIMBRE or INTENSITY afterwards keeps it (a darker CUTOFF stays darker on the next sound); the knob shows the resulting value. Live knobs push only SOUND page parameters, relative to all that.

**DESIGN > SOUND (the sound page):** one frame on every track: the sound first, then **7 DRIVE / CRUSH**, then **8 the performance pair**. Drums: 1 TIMBRE / INT, 2–3 each element's ATTACK / DECAY, 4 both elements' pitch, 5–6 their character, 7 DRIVE / CRUSH, 8 ROLL RATE / BALANCE — KICK (BD body + CLK click): BD PITCH / CLK PITCH, SWEEP / SWP TIME, CLK RESO / CLK NOISE; SNARE (BD body + MTL wires): BD PITCH / MTL PITCH, SWEEP / SWP TIME, MTL TONE / MTL NOISE; HAT (CLK + MTL): CLK PITCH / MTL PITCH, CLK RESO / CLK NOISE, MTL TONE / MTL NOISE; PERC (BD + CLK + metal; the step's note sets the pitch): DETUNE / INTVL, SWEEP / SWP TIME, CLK PITCH / CLK NOISE — PERC's metal attack and decay sit halfway (in time) between the body's and the click's, and BALANCE trades the body against click + metal. Drums have no FUNC layer yet. PAD and LEAD (held notes, so the tail is on the page): 1 TIMBRE / INT, 2 OSC1 ATK / REL, 3 OSC2 ATK / REL, 4 CUTOFF / RESO, 5 FLT ATK / FLT DEC, 6 FLT ENV / FM LVL, 7 DRIVE / CRUSH, 8 LEAD SLIDE / DETUNE, PAD CHORD / DETUNE; FUNC: each oscillator's DECAY / SUSTAIN on 2–3 and PAD UNISON under 8 (plus FEEDBACK on 1, CARRIERS on 4). **BASS** (one amp envelope for both oscillators, and its own filter envelope — hold notes with SUSTAIN while FLT DEC snaps the filter shut, for acid): 1 TIMBRE / INT, 2 ATK / DEC (FUNC: SUS / REL), 3 FLT ATK / FLT DEC, 4 CUTOFF / RESO, 5 **DUCK / DUCK REL** (sidechain: every KICK hit pulls the bass down by DUCK and lets it back over DUCK REL — it follows the kick's notes, so it pumps even with the kick turned down), 6 FLT ENV / FM LVL, 7 DRIVE / CRUSH, 8 SLIDE / SUB; FUNC DETUNE under 8. The five sounds are evened out in loudness (a hidden output gain after DRIVE). **PLUCK** (one envelope; onboard tempo-synced delay + short room): 1 TIMBRE / INT, 2 ATTACK / SUSTAIN (raise SUSTAIN and a pluck rings on, up to a held pad), 3 DLY TIME / DLY FDBK, 4 CUTOFF / RESO, 5 FLT ATK / DEC, 6 FLT ENV / FM LVL, 7 DRIVE / CRUSH, 8 CHORD / DETUNE; FUNC DECAY / RELEASE on 2 (short RELEASE by default, so notes never smear), DLY MIX / VERB on 3 (both 0 on a new sound: dry until turned up), UNISON on 4, ARP OCT on 7, ARP / ARP RATE on 8. SHAPE (the wave) is TIMBRE's. **Live knobs** (defaults; LIVE 3 / 4 with FUNC): KICK ATTACK / DECAY, SNARE SNAP / DECAY, HAT BRIGHT / DECAY, PERC KNOCK / DECAY (all drums: VOLUME / GRIT), every synth has **CUTOFF** first: BASS CUTOFF / ENV (VOLUME / GRIT), PAD CUTOFF / LENGTH (VOLUME / WIDTH), LEAD CUTOFF / GRIT (VOLUME / LENGTH), PLUCK CUTOFF / **NOTES** (**SUSTAIN** / SPACE; SUSTAIN raises ATTACK, DECAY, SUSTAIN and the filter decay together — right, each note fades in and rings on, an arp of swelling notes up to a held pad; left, tighter — RELEASE stays as set; SPACE rides the onboard delay + room; PLUCK's VOLUME is on the MIX page) — NOTES plays 1 to all of the chord's tones, added in order root, 5th, 3rd, 7th, 9th, 11th (pick the chord type with CHORD).

**OCTAVE** (synths) has no knob: in DESIGN, **OCT − / +** step the selected synth's OCTAVE (−4 to +4, saved with the pattern's patch); elsewhere, and on drums, they move the keyboard.

**FUNC** (beside PLAY; keyboard Z): hold it and the knobs show their second layer (the screen says FN); a quick tap latches it on / off (for a mouse). SOUND with FUNC: the synth layers are listed with each type above; drums have only the track setup slots below. SHAPE and FM RATIO are part of each sound's character, set by TIMBRE. Empty FUNC slots do nothing. **Pages:** DESIGN has SOUND (the selected track's sound), MIX and PROJECT. MIX and PROJECT are global (one knob per track); in DESIGN a plain tap on a track button opens its SOUND page. **SOUND with FUNC** also holds the track's setup in the same slots on every type: PRESET (module 1 top), **MID FREQ** (4 bottom: the centre of its MID CUT; per type defaults KICK 350 Hz, SNARE 500, HAT 2 k, PERC 450, BASS 350, PAD 500, LEAD 1 k, PLUCK 800), LIVE 1 / 2 (5) and LIVE 3 / 4 (6): what the live knobs control (LIVE 3 / 4 with FUNC held in RECORD / PLAY). **MIX**: VOLUME on top, PAN below; with FUNC, SEND level on top and **MID CUT** below (the track's own cut after DRIVE: one knob deepens it to 18 dB and widens it from a notch to a broad scoop). **PROJECT**: TEMPO, SWING, MASTER on top; every track's **ACC/GHOST** below (how far accents and ghosts sit from normal hits — 100 % as designed, 0 % every hit the same, 200 % twice the difference, both ways at once); with FUNC every synth track's **TRIM** below (how long each sequenced note's last step is held, 1/8 step to 2 steps, 1 = as entered — short for tight plucks and stabs; tied, RING and SLIDE notes keep their length, only the end moves; it can also be a live knob). CHORD for PAD and PLUCK is on their SOUND page. **DRIVE** on every track is level-compensated: the track is turned down as DRIVE rises (about +2.5 dB left at full drive), so it adds colour rather than volume; VOLUME itself is untouched. Synth envelopes are plain ADSR: DECAY falls to SUSTAIN, RELEASE is as set (no hidden stab rule).

**No safe limits:** ranges go well past sensible (drive to 200×, resonance to self-oscillation, pitch sweeps of 8 octaves, decays to 20 s, LFO pitch to 48 semitones, tempo 40-300). The master runs through a clean look-ahead limiter (−1 dBFS ceiling), so the output never clips and is not coloured below the ceiling.

**Sounds: TIMBRE and INTENSITY.** Every track has two macro knobs at the start of its sound page. TIMBRE travels through five designed sounds, blending every parameter between them; INTENSITY damps (left) or excites (right) the result, changing character rather than loudness. The detail knobs show what the macros set and can fine-tune it until a macro is turned again. Presets are the named TIMBRE points.

**Loudness:** every TIMBRE sound on every track plays equally loud at the track's default VOLUME (a hidden output gain per sound and per type), so switching sounds never jumps in level. FLT DEC has 1 s at the middle of its knob (2 ms … 10 s).

Five sounds per type. **Envelopes are the type's own, not TIMBRE's:** the drums' decays and ring lengths and the synths' whole amp ADSR (ATTACK / DECAY / SUSTAIN / RELEASE of both oscillators) and their width (DETUNE, UNISON) stay as you set them whichever sound is chosen (INTENSITY never changes them either), so sounds can be swapped mid-groove without the envelope going out of whack. TIMBRE still shapes the filter envelope (part of each sound's character). **Except BASS and PLUCK:** each of their sounds brings its whole character, amp envelope and width included, and your SOUND page changes ride on top as offsets.

Chords: MAJOR, MINOR, MIN7, MAJ7, DOM7, MIN9, MAJ9, DOM9, MIN11, SUS4, 5TH, 5TH+OCT, MAJ11.

**LFO:** one LFO, opened with the **LFO** button after FX 1-3 (knobs and screen show it; FUNC + a channel button puts that track on / off it, like a send; a plain tap goes back to the tracks, on that one). Fourteen knobs, two per module: RATE / SHAPE (tempo-synced 4 bars … 1/64 with triplets and odd / dotted ones — 3 BAR, 1.5 BAR, 3/4, 3/8, 5/16, 3/16 — that drift against the loop; sine, square, triangle, saw down, saw up, sample+hold — each starts at its peak so a retriggered LFO hits with the note (made for stabs), except saw up, which rises to end at its peak), MORPH (blends the shape continuously into the next one: base shape + fine-tune) / FM MOD (swings the synths' FM level, ±depth around its set value, like VOL MOD does the level), PHASE / SMOOTH (slew), FADE IN (up to 4 bars, from PLAY or each note) / RETRIG (FREE = locked to the song, NOTE = restarts on each of the track's notes), VOL MOD / PITCH MOD (±48 st), FILTER MOD (±8 octaves on the sound filter) / PAN MOD, SEND MOD (pushes the send level, for dub throws) / SPREAD (offsets each track's phase, so tracks move against each other). Rate and depths can be put on live knobs. Older saves: tracks that used their own LFO join the shared one.

**Buses in RECORD / PLAY:** with FX 1-3 or the LFO open, **FUNC + a channel button** puts that track on / off the bus; a **plain tap** goes back to the tracks with that one selected.

**Bus compressors:** FX 1, FX 2 and FX 3 each end in the same compressor, in series, for an even level: **THRESH / RATIO** (module 7) and **ATTACK / RELEASE** (module 8), with automatic make-up so it holds the level up rather than dropping it. RATIO 1:1 = off. On FX 2 / 3 it holds the summed returns of the four effects (DELAY, DISTORT, CHORUS, REVERB; modules 5-6 are free).

**FX 1-3 / LFO buttons** (RECORD, PLAY and DESIGN): a tap shows that bus's knobs (tap again — or a DESIGN page button — to go back); **FUNC + FX button** puts the selected track on / off that bus. LFO RATE runs from 4 BAR to 1/64, including dotted and odd values (7/8, 3/4, 5/8, 7/16, 3/8, 5/16, 3/16 — the syncopated house stab — 3/32) and triplets.

**FX 1 — drum bus:** tracks on it pass *through* it, so the filter really darkens (or thins) them and the reverse sits under the drums themselves. Transparent at its defaults. Three effects, four knobs each (two modules per effect): **REVERSE** (a reverse delay / reverse reverb: the drums are recorded in tempo-synced slices — REV LEN 1/16 … 1 bar — and each is played backwards while the next records, so hits swell in towards where they land; REVERSE = how much, REV FDBK = reverse echoes of the echoes, SMEAR = diffusion into a reverse-reverb wash), **DISTORT** (DRIVE 0-60 dB, TONE, CRUSH, LEVEL), **FILTER** (one DJ-style knob: left of centre a low-pass down to 30 Hz, right a high-pass up to 16 kHz, centre OFF; RESO to self-oscillation, ENV follower ± up to 8 octaves, ENV REL). Chain: reverse → distort → filter.

**FX 2 / FX 3 — sends:** four effects each, WET (labelled with the effect, top row) and DEPTH (bottom row): DELAY (feedback; tempo-synced, FX 2 = 3/16 dub, FX 3 = 1/4), DISTORT, CHORUS, REVERB; then the bus compressor. (MID CUT is per track, on the MIX page.) A track goes to one send (own SEND LVL, taken before the drum bus), and can be on FX 1 at the same time.

**Routing:** a new project routes nothing — no track on FX 1-3 or the LFO, PLUCK's onboard delay / room dry — so all you hear is the sound engines, clean to record track by track. Older saves keep their routing (old delay send → FX 2, reverb send → FX 3; drum tracks join FX 1).

**Master:** TEMPO and MASTER (the output level, before the limiter). No master colouring: what each track sounds like on its own is what it sounds like in the mix.

**Sequencing:** notes last one step by default; hold a key + ▶ to tie in step entry; live-recorded notes keep their held length; while recording the strip follows the playing 16-step block. **RING** (armed like ACCENT): the hit rings until the next hit or rest on its track — pitched notes are held, drums stretch each layer's own decay x3 and add a fixed extension (0.6 s on every type), so the DECAY knobs set how long rings last, choked by the next hit. **REST** places a stop marker (drums: arm REST, tap steps; step entry: at the cursor). Keyboard starts on A; dividers mark groups of four.

**Time signature, STEPS, triplets:** **TIME SIG** (DESIGN > PROJECT, knob 4: 4/4, 3/4, 2/4, 5/8, 7/8 (4+3+4+3), 11/16, 13/16, 15/16) darkens strip steps: each bar is still one 16-step block, and the dark steps take no time, so 3/4 plays 12 and 7/8 plays 14 per bar. Bar lines follow it (pattern switches, song rows, RESET, whole-bar LFO rates); while playing a change lands on the next bar line. **STEPS** (the steps button, per track and pattern): a tap turns STEPS mode on (lit) — the strip shows which steps play and a tap switches a step on or off (its note stays, unheard while off); hold STEPS + ◀ / ▶ = the pattern one bar shorter / longer (16-64). A track with steps switched off (or a dark one switched on) loops at its own length and drifts against the bar until its pattern is switched: a switch lands on a bar line (on a drifting track the next one, from its first step). Dark steps show dashed on the strip and as a dot on the screen; step entry skips them. **FUNC + BAR** cycles NORMAL / DOUBLE / HALF / **TRIPLET** time: triplets darken the 4th step of each group and stretch the other three to fill the beat (12 per 4/4 bar). RESET always lands on the time signature's bar line, whatever each track's STEPS. **Hold track buttons while tapping RESET** to leave those tracks out.

**Ties on the strip:** when a synth / PERC track shows steps (placing RING / SLIDE / ACCENT / GHOST, or CLEAR held), steps a note is tied over show as a line through the middle of the button; tap one to put the flag on that note. A held note that changes dynamic (a slide from a ghost into an accent) moves its level and tone over a few milliseconds instead of jumping, so no click.

**Saving:** SAVE (patterns / patches, above). PRESET (SOUND + FUNC) still loads the factory sounds and earlier USER patches into the current pattern's patch. **Projects** (stopped only): 64 slots in 4 banks of 16, each project with its tracks' sounds and its own working copy (unsaved edits are kept when you switch). **SAVE PROJECT** opens SAVE: name the project on screen (◀ / ▶ move along the name; knobs 1-4 dial capitals, lower case, digits, symbols at the cursor — each starts on a space and the character only changes once a knob is turned; up to 16 characters), hold BAR + ◀ / ▶ to change bank, then tap a strip step to save into that slot (a slot holding another project needs a second tap to overwrite; its own slot just saves). **FUNC + SAVE PROJECT** opens LOAD: the bank's 16 names on screen and on the strip (lit = used, cursor = open), ◀ / ▶ change bank, tap a slot to load it, hold CLEAR + tap a slot twice to delete it. Tap SAVE PROJECT again to leave; RESET returns to the saved versions. All in this browser's local storage (each slot keeps a working copy of unsaved edits); on claude.ai the working project is also mirrored to the artifact's store. The save format is forgiving: notes carry over across format changes. **Cloud slots (claude.ai Artifact):** all 64 slots are also kept in the artifact's database, so every device that opens the Artifact has the same slots (merged on start and when SAVE / LOAD opens; each save or delete is copied up at once). Nothing is lost in a merge: the same project keeps its newest save; two different projects saved in one slot independently — the earlier save keeps the slot, the later one moves to a free slot; deletes travel as markers. The GitHub Pages build keeps its slots in that browser only.

Keyboard: Space play/stop · Z FUNC (hold) · 1-8 select channel · Shift+1-8 mute · Q-I / A-K the strip.

**Live recording and latency:** notes played live while recording land on the step you heard, not the one the engine was on when your tap arrived. The browser's reported output latency (shown as OUT …MS) plus a small allowance for touch is taken off, so recording works with the delay a phone or tablet adds (also Bluetooth, if the device reports it).

**MUTE / SOLO:** each track has MUTE (M) and SOLO (S) under its button (keyboard Shift+1-8 / Alt+1-8). Any SOLO on mutes every track that is not soloed; SOLO is a performance switch and is not saved. **LEAD** plays up to 3 voices, so a note's release rings under the next one.

**SLIDE** on the synths is one held note: from the SLIDE note through the note it lands on, the level stays full (no decay) until that last note ends.

**PLAY pages:** in PLAY the page buttons read SOUND and MIX. SOUND (where PLAY always starts) is the live knobs; MIX is the same MIX page as in DESIGN (VOLUME / PAN, with FUNC SEND / MID CUT), so you can ride the mix while performing. PROJECT stays in DESIGN.
