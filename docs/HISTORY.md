# History

How GrooveAccess got here: what changed, version by version (the project format's
`PROJECT_VERSION` numbers, v10 ... v40). This is a log, not a description of the app now:
many entries were later changed or reversed. For how things work **now**, read `CLAUDE.md`
(Current state) and `ARCHITECTURE.md`; come here when you need to know why something is the
way it is, or what an old save looked like (the load migrations in
`src/engine/projectFile.ts` are named after these versions).

Add one entry per change at the end (newest last), with the version if the save format moved.
