How TIMBRE moves between sounds

Drag a knob up or down, scroll on it, or use the arrow keys. Tap a sound name to jump TIMBRE to it. Space plays and stops. INT works the same way in every option. The sounds use each track's default envelope and width settings, not your SOUND page adjustments.
