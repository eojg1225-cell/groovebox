What to listen for

FM LEVEL sets how much of the FM pair you hear against the plain sine, and how hard it modulates. FLT ENV makes each note open bright and settle, which is where the "dancey" bite comes from. Sweep FM LEVEL from 0 up on 2 and then on 3: on 2 the note drops as the FM takes over, on 3 it should stay where it is. Raise OCTAVE on whichever sits too low.
